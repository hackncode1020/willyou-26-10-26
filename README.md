# Will you be mine? 💖 — the website she can't say NO to 😂

A tiny proposal page with two buttons: **YES** and **NO**.
Try to tap **NO** and it runs away across the screen, shrinks, and begs you to reconsider
("Are you sure? 🥺", "Think again 😢", "Pakka? 💔", "Last chance 😭") while **YES** grows bigger and glows.
Tap **YES** → heart explosion 💥, floating hearts, a happy bouncing bear and *"Yayyy! I knew it 💞 For your love"*.

### 🔗 Live demo
**https://willyou-hackncode.sites.tab.bot/**

### ✍️ Personalise it
Add their name with `?name=`:

```
https://willyou-hackncode.sites.tab.bot/?name=YourPerson
```

The question becomes **"YourPerson, will you be mine? 💖"**. After they say YES there's also a box to make a link with any name and share it.

### 🛠 Built with
Plain **HTML + CSS + JavaScript**. No libraries, no images.
- `script.js`: the runaway NO button, YES growth and glow, and the canvas heart explosion (all hearts are drawn with bezier curves)
- `style.css`: the romantic dark-pink theme
- `index.html`: the page, with the bear drawn in SVG

Runs on any phone. Fork it, change the text, and send it to your person 💌

### ▶️ Run locally
Open `index.html` in a browser, or run `python3 -m http.server` and visit `http://localhost:8000`.
